## ✨ ویژگی‌ها

- شامل مثال‌های متنوع برای تمرین مفاهیم مختلف JavaScript
- استفاده از HTML و JavaScript خالص (Vanilla JS)
- مناسب برای مبتدیان و کسانی که قصد تقویت مهارت‌های JavaScript خود را دارند

## ⚙️ پیش‌نیازها

- مرورگر وب مدرن (مانند Chrome، Firefox یا Edge)
- ویرایشگر متن (مانند Visual Studio Code)

## 🚀 نصب و راه‌اندازی

1. مخزن را کلون کنید:

   ```bash
   git clone https://github.com/MansourLiaghat/java-script.git
   cd java-script
   ```

2. فایل‌های HTML موجود را با مرورگر خود باز کنید و عملکرد آن‌ها را بررسی کنید.

## 🧪 نحوه استفاده

- هر فایل HTML در این مخزن یک مثال مستقل است.
- برای مشاهده عملکرد هر مثال، کافی است فایل مربوطه را در مرورگر خود باز کنید.
- می‌توانید کدها را تغییر دهید و نتایج را به‌صورت زنده مشاهده کنید.
