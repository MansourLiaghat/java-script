## ✨ ویژگی‌ها

- شامل مثال‌های متنوع برای تمرین مفاهیم مختلف JavaScript  
- استفاده از HTML و JavaScript خالص (Vanilla JS)  
- مناسب برای مبتدیان و تقویت مهارت در JS  

## ⚙️ پیش‌نیازها

- مرورگر مدرن (Chrome، Firefox، Edge و ...)  
- ویرایشگر کد مانند VS Code  

## 🚀 نصب و راه‌اندازی

1. کلون کردن مخزن:

   ```bash
   git clone https://github.com/MansourLiaghat/java-script.git
   cd java-script
   ```

2. اجرای هر فایل HTML در مرورگر:

   فقط فایل `.html` مربوطه را باز کنید و نتیجه را ببینید.

## 🧪 نحوه استفاده

- هر فایل HTML یک مثال مستقل است  
- کافی‌ست آن را باز کرده و عملکرد کد را ببینید  
- می‌توانید کد را تغییر دهید و تأثیر را بلافاصله مشاهده کنید
